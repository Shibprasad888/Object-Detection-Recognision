# User Manual

## Keyboard Shortcuts

- Q – Quit
- R – Register object
- L – Draw line
- Z – Draw zone
- S – Search objects
- T – Toggle trails
- P – Pause / resume
- Space – Take snapshot
- F11 – Fullscreen
- F1 – Help

## Tips

- Start with a well-lit scene for reliable detection.
- Use zones and lines to define analytics regions.
- Review alerts and reports after long runs.
